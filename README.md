High-Performance Data Pipeline Engine

Project Overview
A Python-based web application that uploads, cleans, validates, and processes CSV and Excel files using Flask and Pandas.

Technologies Used
- Python
- Flask
- Pandas
- NumPy
- Multiprocessing
- HTML and CSS

Key Features
- CSV and Excel file upload
- Data cleaning and transformation
- Missing value handling
- Duplicate record removal
- Parallel processing using multiprocessing
- Cleaned data export
- JSON report generation
- Logging and processing metrics

Installation

pip install -r requirements.txt


Run the Application
python app.py


Open `http://127.0.0.1:5000` in your browser.

 Project Purpose
This project demonstrates data processing, automation, and performance optimization using Python.
